# Task Management Frontend

React frontend for the Task Management application.

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- i18next

## Features

- Login and registration
- Turkish and English language support
- Protected dashboard
- Task CRUD operations
- Responsive interface
